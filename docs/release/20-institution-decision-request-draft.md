## 왜 지금 필요한가

아래 결정이 나와야 개인정보 관련 기능(영수증 사진 읽기·쉬운말 요약·처리방침 공개)을 마감 전에 완성할 수 있다. 개발은 결정이 나온 뒤 약 1주 안에 반영한다(10/14~10/20). 회신이 늦으면 §4 의 방식으로 AI 기능을 이번 출시에서 빼고 결정 후 켠다.

## 1. 앱에서 외부(미국)로 나가는 정보 (결정의 배경)

| 기능 | 보내는 정보 | 가릴 수 있는가 |
|---|---|---|
| 영수증 사진 읽기(OCR) | **영수증 사진 원본** | 불가 — 사진 자체가 정보 |
| 쉬운말 요약 | 당사자가 직접 쓴 강점·어려움·바라는 삶(**민감정보**), 서비스 이름 | 일부 — 당사자·대리인 이름은 가림, 글 속 제3자 이름 등 자유서술은 완전하지 않음 |
| 활동 제안 | 활동 맥락 | 일부 |
| 저장(Supabase) | 앱 전체 정보 | 서울 리전(`ap-northeast-2`)이라 **국외이전 아님**(2026-09-23 확인) |

수령 회사: Anthropic(Claude API, 미국). 학습에 쓰지 않고, 기본 보관 7일이며, 위탁계약은 약관으로 자동 적용된다(doc15 §3).

## 2. 결정해 주실 것 (회신 기한 10/13)

**D1. AI 기능의 국외이전 근거**
- [ ] 영수증 사진 읽기(OCR): **A안 별도 동의**(당사자, 발달장애 당사자는 법정대리인) · **국내 대안으로 교체** · **기능 제거** 중 선택
- [ ] 쉬운말 요약·활동 제안: **B안 이름·식별정보를 가려서 전송**으로 확정(권고, doc15 §7). 자유서술에 남는 제3자 이름의 한계를 감수하는지 확인
- [ ] (A안을 택하는 경우) 동의서 항목 — 국외이전·AI 분석·민감정보·(필요 시) 법정대리인 — 항목별 구분, 거부할 권리, 거부해도 쓸 수 있는 대안(AI 끄기)
- [ ] AI 결과물 표시 문구(「AI 보조·담당자 최종 검토」)가 당사자 화면의 쉬운 표현("컴퓨터")으로도 충분한지

**D2. 처리방침 확정값**
- [ ] 시행일 · 최종 문안 승인
- [ ] 개인정보 보호책임자 연락처
- [ ] 일반 개인정보 보존 기간(감사 접속기록은 730일로 이미 확정)
- [ ] 고유식별정보(주민등록번호 등)를 실제로 수집·보관하는지(동의 항목은 있으나 보관 위치 확인 필요)
- [ ] 외부 CDN(jsdelivr) 사용을 처리방침에 고지할지

**D3. 기관 담당자가 직접 하실 일(대시보드 작업)**
- [ ] Supabase **위탁계약(DPA) 대시보드 서명**
- [ ] Vercel **Web Analytics·Speed Insights**가 모으는 항목·처리 위치 확인과 DPA 수락 — 필요 없다고 판단하면 **제거**도 선택지

## 3. 권고 (doc15 §7 기본 노선)

1. 저장은 서울 리전 + DPA 서명으로 종결
2. 요약·활동 제안은 **마스킹 강화(B안)** — 가리면 국외이전이 아님
3. OCR 만 **A안 동의 또는 국내 대안/제거**(원본 사진이라 가릴 수 없음)
4. AI 결과물 표시·사람 최종 검토 원칙 유지(AI 기본법)
5. 처리방침 발효

## 4. 회신이 늦을 때 (제안 — 사용자 확정 필요)

10/13 까지 D1 이 결정되지 않으면 AI 기능(영수증 사진 읽기·쉬운말 요약·활동 제안)을 **이번 출시에서 제외**하고, 결정 후 후속 배포로 켠다. 그때 영수증은 직접 입력으로 등록하게 된다(이 흐름이 끊기지 않는지는 개발 쪽에서 확인 중이다). D2 는 처리방침 시행에 필요하므로 회신이 없으면 앱 마감일을 기관과 다시 맞춰야 한다.

## 5. 회신 방법

각 체크박스에 표시하고 D2 의 값을 적어 회신한다. 결정은 `decisions.md` 에 한 줄씩 기록하고 개발에 반영한다.
