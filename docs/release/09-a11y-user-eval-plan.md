# 09 · 접근성 실사용자 심사 계획 (User Evaluation Plan)

> 목적: 코드·자동검사·전문가 검토로 **대체 불가**한 부분 — 장애 당사자가 실제 과업을 수행해 성공률과
> 장벽을 확인하는 **사용자 심사**를 준비한다. 근거: [`07`](07-a11y-kwcag-1st-eval.md) §6-2·[`08`](08-a11y-remediation.md) §4.
> 기준: KWCAG 2.2. ★품질인증 사용자 심사 성공률 기준(100%)·절차는 **인증기관 공지로 재확인 필요**(needsVerification).

## 1. 대상 평가자 (장애유형 — 사용자 지정)
당사자 화면은 **핵심 대상**이므로 유형을 넓게 모집한다. 유형당 **최소 3~5명** 권고(인증기관 기준 재확인).

| 유형 | 주 보조수단 | 이 앱에서 특히 볼 것 |
|---|---|---|
| **지적·발달장애**(핵심 대상) | 쉬운 말·그림·보호자/실무자 동석 | 이해도·오류 복구·맥락 변화 혼란·기억 부담 |
| **시각(전맹)** | 스크린리더(NVDA/VoiceOver/TalkBack) | 낭독 순서·레이블·대체텍스트·초점 복귀 |
| **저시력** | 화면 확대 200%+·고대비/노랑/글자확대 테마 | 확대 시 레이아웃 붕괴·잘림·대비 |
| **청각** | 소리 끔 | 소리 단독 정보 없음(자막·시각 대체) |
| **뇌병변(지체 포함)** | 키보드 전용·스위치·큰 터치 | 초점 순서·가시성·큰 터치타깃·오조작 취소·시간 압박 |

## 2. 환경 준비
- **테스트 계정**: 데모 로그인(`/login` 하단 "관리자/담당자/당사자로 둘러보기") — 실 비밀번호 불필요.
  (또는 시드 계정. 자격증명은 진행자가 직접 입력 — 에이전트 대행 금지.)
- **보조기기**: 시각=NVDA(Win)/VoiceOver(Mac·iOS)/TalkBack(And) · 저시력=OS 확대·앱 테마(더보기→화면) ·
  뇌병변=키보드만/스위치 · 청각=시스템 음소거.
- **기기**: 당사자 화면=모바일(≤600px) 우선 + 데스크톱. 실무자·관리자=데스크톱 우선.
- **진행자**: 과업 안내·관찰·기록(개입 최소, 막힌 지점·시도·정서 반응 기록). 발달장애 평가자에는 동석 지원.

## 3. 과업 시나리오 (역할 × 장애유형) — 앱 실제 플로우
각 과업: **성공 / 부분성공(도움받아 완료) / 실패** + 장벽 메모 + KWCAG 검사항목. 검사항목은 `6.4.1(2.4.1)` 형식.

### 3-1. 당사자 (모바일 우선 · 핵심 대상)
| # | 과업 | 유형 초점 | KWCAG |
|---|---|---|---|
| P1 | 로그인해 홈에서 **내 남은 예산**을 찾아 말하기 | 전체 | 6.4.2·7.3.2 |
| P2 | **지출 기록**: 영수증 사진·금액·항목 입력해 저장 | 지적·뇌병변 | 7.3.2·6.1.3·7.3.1 |

## 4. 기록·판정
- **과업 성공률** = 성공 / 전체(부분성공은 별도 집계). 유형별·역할별·과업별로 집계.
- 각 실패·부분성공에 **장벽 서술 + 심각도(치명/높음/보통/낮음) + KWCAG 태그 + 재현 경로**.
- 자동 감사에서 `manual` 로 남은 항목(07 §6-1: 5.3.3·5.4.4·6.3.1·6.5.1·6.5.2·7.2.2 등)과 연결해
  "사람이 무엇을 확인했는지" 명시.
- 정서·인지 부하 관찰(발달장애): 망설임·재시도·포기·불안 표현도 기록(정량 밖 중요 신호).

## 5. 결과 환류 (개발 축)
- findings → 심각도순 → **W 계약(회귀 테스트) → U 수정 → 재게이트** 슬라이스로 처리(관리자 QA·a11y remediation과 동일 하네스).
- 가능하면 [`08`](08-a11y-remediation.md)의 소스 스캔 가드에 새 규칙 추가로 **회귀 고정**.
- 재심사(regression eval)로 수정 확인.

## 6. 윤리·동의 (발달장애 당사자 참여)
- **쉬운 말 설명·동의서**(easy-read), 필요 시 보호자/실무자 동석. 언제든 중단 가능·불이익 없음 고지.
- 실패는 **앱의 문제이지 사람의 문제가 아님**을 분명히(평가 대상은 앱). 압박·유도 금지.
- 충분한 시간·휴식, 참여 보상, 개인정보 최소 수집·분리 보관. 세션 녹화는 별도 동의.
