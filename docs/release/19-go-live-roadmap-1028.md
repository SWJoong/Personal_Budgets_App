## 1. 목표와 「마무리」의 정의

마감은 **2026-10-28(수)**. 「마무리」는 아래 4가지가 닫힌 상태다(Go/No-Go 기준은 §6).

1. P0 개인정보·운영 항목 닫힘
2. 핵심 흐름 기능 QA 통과
3. 운영 전환 하드닝 완료
4. 알려진 결함 목록 합의(출시 후 처리분 명시)

범위 밖: 보류(deferred — 코디네이터 세분화·멀티테넌시·M:N 공동배정·그래프DB 등)와 P3(doc14).
