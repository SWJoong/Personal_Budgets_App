## 0. 적용 범위(Tier) — 무엇이 N/A인가

KRDS 는 3개 상징 계층으로 나뉜다. 우리 앱은 **자체 상징 + 공통** 계층에 해당(사용자 확정).

| 계층 | 원문 대상 | 우리 앱 | 판정 |
|------|-----------|---------|------|
| 정부 상징 | .go.kr 공식 정부서비스 | 아님(복지기관 앱) | **대부분 N/A** |
| **자체 상징** | KRDS 채택 비-정부 서비스 | **여기 해당** | **적용** |
| **공통** | 모든 서비스 | 해당 | **적용** |

### N/A (근거를 결과서에 명시)
- **공식 배너 / 운영기관 식별자** — 정부 상징 전용.
- **Pretendard GOV / 본문 17px** — 정부 상징 전용. 우리는 자체 상징 기준 **Pretendard · 본문 16px↑**.
- **정부 색상 팔레트(Primary/Secondary/Gray/System 색상값)** — 정부 상징 전용. 우리는 자체 팔레트 + 공통 규칙(일관성·대비).
- **브레드크럼 / 콘텐츠 내 탐색(목차) / 페이지네이션** — 탐색 depth ≤2, 목록 짧음 → 도입 안 함(사용자 확정).
- **서비스패턴 방문·검색·정책정보 확인** — 해당 플로우 없음. (로그인·신청은 적용)

### 우리가 KRDS보다 엄격히 유지(다운그레이드 금지)
- **터치 타깃 44×44px**(KRDS 최소 24px) — 발달장애 사용자 대상.
- **줄 간격 1.85 목표**(KRDS·WCAG 최소 1.5) — Easy Read.
- **아이콘 항상 텍스트/레이블 동반** — 단독 아이콘 금지.

## 1. 스타일 (색상·서체·형태)

**색상**
- [ ] 배경·테두리·텍스트 색상 일관 사용(같은 의미=같은 색).
- [ ] 상태(hover/focus/active/선택/비활성) 기본색 기준 증·감 규칙.
- [ ] **색상만으로 정보 구분 금지** — 색 + 아이콘/텍스트/패턴.
- [ ] 텍스트/배경 대비 **4.5:1 이상**(큰 텍스트 3:1). ※ `text-zinc-400` on white = FAIL → 500/600/700.

**서체**
- [ ] 본문 기본 **16px 이상**. 고딕(Pretendard) + 굵기 2가지 이내.
- [ ] Title/Heading 은 본문보다 굵거나 크게. 여러 줄 행간 **1.5배↑**(목표 1.85, `leading-relaxed`↑).
- [ ] 이탤릭 남용·의미 없는 밑줄 금지(밑줄=링크 신호).

**형태**
- [ ] 컨테이너 둥글기 일관, 둥글기로 내부 콘텐츠 가림/잘림 없음.

## 2. 컴포넌트

**헤더** — 로고/제목 좌측상단·스크롤 고정, 아이콘 버튼/링크에 텍스트 레이블(또는 `aria-label`).
**푸터**(모바일 TabBar 대체 — 부분 적용) — 서비스 정보·연락처·**개인정보 처리방침** 링크, 일관 위치.
**건너뛰기 링크(✅ 적용됨)** — 모든 화면, 3개 이내, 첫 항목=본문(`#main-content`), 평소 `sr-only`·포커스 시 노출, 목적지 실제 연결.
**메인/사이드 메뉴·네비게이션** — **현재 화면 `aria-current="page"`**, 계층 ≤3(사이드 ≤2), 쉬운 용어, 마우스오버 확장 금지·`aria-expanded`, 키보드(Tab·방향키·Esc).
**링크** — 색상 단독 구분 금지(밑줄/아이콘), 목적지 예측 가능 레이블("여기/클릭" 금지), 이메일·전화 `mailto:`/`tel:`, 외부 이동 링크 명시.
**버튼** — 그룹 크기 동일·한 화면 최상위 강조 1개, **동사형** 레이블, **더블클릭/연타 방어(중복 제출 방지)**, 키보드 실행.
**라디오/체크박스** — 세로·레이블 오른쪽·가나다순; 라디오 다중선택 금지·많으면 셀렉트·정확입력 시 기본선택 없음·"해당없음/잘모름"; 체크박스 "전체 선택"은 **indeterminate**; `fieldset/legend` 또는 `role=radiogroup`·키보드.
**셀렉트** — 레이블·선택값 표시, **값 변경만으로 자동 제출 금지**, 키보드.
**날짜 입력** — 레이블 + 어떤 날짜인지 설명 + **형식 도움말**(YYYY-MM-DD), 상대날짜엔 명확한 표현, 자주 쓰는 날짜 자동완성 고려.
**텍스트 입력/영역** — **보이는 레이블**, **플레이스홀더를 레이블/도움말 대체 금지**, **복사·붙여넣기 허용**, 글자수 제한 시 남은 수 안내, 오류 시 `aria-invalid`+`aria-describedby`+`role=alert`.
**파일 업로드(영수증)** — 레이블 + **유형·크기·개수 안내**, 업로드 후 버튼 유지·삭제 버튼, **자동 제출 금지**, 구체적 오류, 파일명 한 줄, 모달에서 다중 업로드 금지.
**태그/칩(영역필터·관계망)** — 레이블 간결, 대화형/비대화형 혼용 금지, 탐색·실행·삭제 키보드.

## 3. 기본 패턴
- **입력폼**: 레이블 위 배치, 필수/오류를 색 외 수단(아이콘·텍스트), 제출 전 검증, 오류 요약+개별 연결.
- **첨부파일(영수증)**: 파일 업로드 기준 + 진행/완료 피드백.
- **필터링·정렬**(거래장부·지도 영역필터): 현재 필터 명시, 초기화, 결과 수 안내.
- **개인 식별 정보 입력**: 최소한만(이름/생년), 이유 안내.

## 4. 서비스 패턴(적용분)
- **로그인**: 방식 명확·쉬운 말·오류 회복 경로(데모 로그인 버튼 동사형).
- **신청(applications)**: 단계 표시(진행률)·각 단계 되돌리기·확인/완료 피드백·결과 확인.

## 5. 검증 방법 — 결과서(P/F/E/N/A) & 점검 도구

판정: **P**(준수)·**F**(미준수)·**E**(예외)·**N/A**(해당없음). E/N/A 는 근거 1줄 필수.

**점검 도구(부록 「도구 활용 방법」)**
- **글자크기/줄간격**: DevTools → 요소 → **Computed 탭** `font-size`/`line-height` 실측(선언값 아님).
- **명도 대비**: CSS Overview → Contrast issues + **실제 화면 병행 확인**.
- **키보드 초점**: Tab 순서(상→하·좌→우 논리 흐름)·포커스 링 가시성·Shift+Tab 역순·Esc.
- **타깃 사이즈**: Computed `height`/`width` ≥ 24px(우리 44px), DigitalA11Y 확장 Touch Target Size 겹침 확인.
- **상태값**: Style 탭 `:hov` 토글 → hover/focus/active/visited/focus-within.
- **100% 배율**: 브라우저·OS 배율 100% 초기화(캐시 비우기 강력 새로고침) 후 점검.

## 6. 관련 기준 연결
- **easy-read-review**: 신규 레이블/도움말/오류문은 쉬운 말 검수 후 확정.
- **KWCAG**(브랜치 `feat/goala-a11y-*`): 대비·랜드마크·초점·대체텍스트와 상호 보완.
- **내부 `.claude/skills/ux-ui/references/design-system.md`**: 색/타이포/간격/크기(44px·4.5:1) KRDS 와 정렬. 폰트는 실제 배포 기준 **Pretendard** 로 통일(문서상 나눔고딕 표기는 갱신 대상).
